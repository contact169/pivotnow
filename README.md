## Contenu

- `index.html` — page complète (HTML, styles inline, scripts Webflow)

Les feuilles de style, scripts et images sont chargés depuis le CDN Webflow (`cdn.prod.website-files.com`) : la page s'affiche telle quelle tant que ces ressources restent en ligne.
